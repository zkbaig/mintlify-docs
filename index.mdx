## How to use this textbook

<CardGroup cols={3}>
  <Card title="1. Orient with the primer" icon="book-open">
    Start with the opening concept map in each module. Capture key definitions and the
    investor lens so you speak the same language in every round.
  </Card>
  <Card title="2. Run the decision checklist" icon="clipboard-check">
    Apply the prompts to your startup today—model runway, metrics, and capital needs to
    pressure-test your plan.
  </Card>
  <Card title="3. Ship the action prompt" icon="bolt">
    Turn learning into output: write the memo, build the model, or draft the investor
    update. Treat every module as a founder deliverable.
  </Card>
</CardGroup>

<Callout type="info" title="Quick checklist">
  - Keep a **single source of truth** for your metrics (MRR, ARR, cash, runway).
  - Refresh your **fundraising narrative** every quarter.
  - Track **milestones that unlock capital** (traction, retention, gross margin, CAC).
  - Use modules as a **pre-meeting audit** before investor conversations.
</Callout>
